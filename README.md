## About

I build the data platforms and distributed systems that analytics and AI applications run on: streaming pipelines, governed data access, metadata infrastructure and cloud-native services. Before moving into data platform engineering I worked on backend systems, serverless APIs and ML inference infrastructure.

## Selected Impact

- **Data platform modernization:** migrated core data pipelines to a managed streaming architecture across 2 deployment environments, coordinating validation, backfills and cutovers.
- **Multi-region expansion:** extended shared data-platform capabilities across 3 geographic regions and 6 business areas, with regional configuration, encryption and access controls.
- **Access governance:** replaced broad shared permissions with team-scoped, environment-aware access controls across 3 deployment environments.
- **Data quality:** built region-aware quality checks that cut false-positive failures across 2 geographies.
- **Inference performance:** reduced image inference latency from about 3 seconds to about 1 second using AWS Lambda and NVIDIA Triton Inference Server.
